# 길건너 플라밍고 (Flamingo Road)

크로시로드(길건너친구들) 스타일의 3D 복셀 아케이드 게임입니다.
분홍 플라밍고가 되어 도로, 강, 철길을 건너 최대한 멀리 가보세요!

**[지금 플레이하기](https://flam-ing.github.io/flaming-games/flamingo-road/)**

## 게임 소개

- 끝없이 이어지는 잔디밭 · 도로 · 강 · 철길을 한 칸씩 폴짝폴짝 건넙니다.
- 도로에서는 알록달록한 자동차와 트럭을 피하세요.
- 강에서는 떠내려가는 통나무와 연잎을 밟고 건너야 합니다. 물에 빠지면 끝!
- 철길은 경고등이 깜빡인 뒤 고속열차가 지나갑니다. 타이밍이 생명!
- 너무 오래 머뭇거리면 화면이 앞으로 밀려나고, 뒤처지면 거대한 큰부리새가 낚아채 갑니다.
- 점수는 도달한 가장 먼 줄 수이며, 최고 기록은 브라우저(localStorage)에 저장됩니다.

## 조작법

### 키보드
| 키 | 동작 |
|---|---|
| `↑` / `W` / `Space` | 앞으로 점프 |
| `↓` / `S` | 뒤로 점프 |
| `←` / `A` | 왼쪽으로 점프 |
| `→` / `D` | 오른쪽으로 점프 |

### 터치 (모바일)
| 제스처 | 동작 |
|---|---|
| 탭 | 앞으로 점프 |
| 위/아래/좌/우 스와이프 | 해당 방향으로 점프 |

우측 상단 버튼으로 소리를 켜고 끌 수 있습니다.

## 기술 스택

- **Three.js** (r160, CDN importmap) — 3D 복셀 월드, 직교 카메라, PCF 소프트 섀도우
- **Vanilla JavaScript** — 단일 `index.html` 파일, 빌드 과정 없음
- **WebAudio API** — 점프·충돌·물튀김·마일스톤 효과음을 코드로 합성 (외부 오디오 파일 없음)
- **HTML/CSS 오버레이 UI** — 타이틀 화면, 점수, 게임오버 패널, 한국어 UI

## 로컬 실행

정적 파일 하나뿐이라 아무 정적 서버로 열면 됩니다.

```bash
python3 -m http.server 8087
# http://localhost:8087 접속
```
