# says — 플라밍고 세이즈 (원작: Clefairy Says, Pokémon Stadium 1 / N64 Kids Club)

> 이 문서만 보고 `games/says.html`을 다시 만들 수 있어야 한다. 확정 사실은 [확정], 출처가 침묵한 부분은 "불명 — 추정: …"으로 표기.

## 1. 한 줄 요약 · 등장 캐릭터와 플라밍고 대체안

**한 줄 요약**: 교실에서 선생님이 칠판에 그리는 화살표 순서(4→6→8→10→12개)를 외웠다가 D패드로 똑같이 입력하는 4인 동시 기억력(Simon Says) 게임. 틀리거나 입력을 안 하면 선생님이 장난감 망치로 때리고(HP −1), 5대 맞으면 탈락. 5라운드 뒤 가장 적게 맞은 쪽이 승리. [확정] 원작 9개 미니게임 중 "가장 어려운 게임"으로 평가됨.

| 원작 요소 | 원작 묘사 | 플라밍고 대체안 (셸 포즈 활용) |
|---|---|---|
| 학생 삐삐(Clefairy) ×4 | 책상 앞에 서서 노래에 맞춰 춤추는 분홍 삐삐, 플레이어 색 리본/번호 | `drawFlamingo` 플레이어 색. 대기 `idle`, 입력 시 방향에 맞춰 `jump`(↑) / `dig`(↓, 고개 숙임) / `run` 좌우 `flip`(←→). 정답 라운드 완료 `fly` 잠깐. 망치 맞을 때 `hit`→`dizzy` 0.8s. HP 0 탈락은 `sleep`(주저앉음). |
| 선생님 삐삐 | 칠판 옆에 선 큰 삐삐, 지시봉으로 화살표를 가리키며 "Clefairy! Clefairy!" 노래. 오답자에게 걸어가 망치질 | 큰 플라밍고(scale 1.6, 금색 `palette.gold`), 안경·지시봉 소품(선분+원). 보여주기 중 `idle`+지시봉 회전, 채점 때 `hit` 모션으로 망치(갈색 사각+손잡이) 휘두름. |
| 칠판 + 화살표 | 초록 칠판에 흰 분필 화살표가 한 개씩 그려짐. 보여주기 후 지우개로 싹 지움 | 상단 중앙 칠판(rr, `#2f5d3a`), 화살표는 흰색 굵은 글리프 `↑↓←→`. 지우기는 0.4s 동안 알파 페이드. |
| 장난감 망치 | 노란 머리 + 빨간 손잡이 삐삐용 뿅망치 | 동일 형태 소품, 맞을 때 `sfx.hit` + 별 파티클. |
| 피격 마크(HP) | 각 삐삐 **머리 위**에 오답 표시가 쌓임, 5개면 탈락 | 머리 위 ○○○○○ → 맞을 때마다 빨간 ✕(`palette.red`)로 채움. |

## 2. 인원 · 시간 · 라운드 구조

- **4인 동시** [확정]. 사람 1~4명 + 나머지 COM. 모두 같은 순서를 같은 타이밍에 본다(개별 순서 아님).
- **제한 시간 없음, 라운드제** [확정]: 총 **5라운드**. 화살표 개수 **4, 6, 8, 10, 12** [확정: "four, four+two, six+two, eight+two, ten+two"].
- **종료 조건** [확정]: (a) 살아남은 플레이어가 1명 이하가 되면 즉시 종료, (b) 5라운드가 끝나면 종료.
- 라운드 1개의 단계 (시간은 불명 — 추정, 원작 영상 체감 기준):
  1. `intro` 0.8s: "라운드 N" 자막, 선생님이 칠판을 가리킴.
  2. `show`: 화살표를 **한 개씩** 그리며 노래. 개당 표시 간격 **0.6s** (라운드 1) → 라운드마다 0.05s 단축, 최소 0.4s. 그려진 화살표는 칠판에 **누적**되어 남는다(끝까지 전부 보임). 원작도 누적 표시라 "종이에 적어 치팅 가능"하다는 언급이 있음 [확정].
  3. `erase` 0.6s: 칠판을 지움. "따라 하세요!" 자막.
  4. `input`: 플레이어가 자유 타이밍으로 순서를 입력. 제한 시간 = **1.0s × 화살표 수 + 2s** (라운드 1: 6s, 라운드 5: 14s) — 불명, 추정. 화면에 타임 바 표시.
  5. `judge` 약 0.6s × (실수한 사람 수) + 0.8s: 선생님이 오답자 앞으로 가서 망치질. 정답자는 `fly` 환호.
  6. 다음 라운드 or 결과.
- 총 소요 약 60~90s.

## 3. 조작

| N64 | 원작 기능 | 우리 액션 |
|---|---|---|
| Control Pad ↑↓←→ | 화살표 순서 입력 [확정: "Control Pad to repeat the pattern"] | `up down left right` (`g.p(i).hit(...)`, 한 프레임 눌림) |
| Control Stick | 불명(모든 출처가 "Control Pad/D-Pad"만 언급) — 추정: 미사용 | `axis()`는 쓰지 않음(오입력 방지). 셸 키 매핑이 `up down left right` 액션으로 이미 통일돼 있으므로 문제 없음. |
| A / B / C | 사용 안 함 | `a`, `b` 무시. |

- **연타/홀드 없음**, 한 번 눌림 = 화살표 1개. 홀드해도 1개만 인식(`hit` 사용).
- **입력 반응 규칙**:
  - `input` 단계에서만 입력 수집. `show`/`erase` 중 입력은 무시(선입력 불가 — 불명, 추정).
  - 같은 프레임에 두 방향 동시 → 먼저 정의된 순서(up,down,left,right) 중 하나만 채택.
  - 입력마다 그 플레이어의 플라밍고가 해당 방향 포즈로 0.25s 춤추고 `sfx.beep`(방향별 음: ↑880 ↓440 ←660 →550Hz, 0.08s).
  - 각 플레이어는 **정답 개수만큼 입력하면 완료**(`done`). 완료 후 추가 입력 무시.
  - 오답을 눌러도 즉시 탈락하지 않고 입력은 계속 받는다(채점은 라운드 끝). 화면에 즉시 X 표시는 하지 않는다(원작은 입력 단계에서 정오 피드백을 주지 않음 — 불명, 추정).
  - 시간 종료 시 미완료자는 "입력 안 함"으로 처리.
  - 생존자 전원이 `done`이면 타임 바가 남았어도 **0.8s 뒤 입력 단계 종료**(원작은 전원 완료 시 바로 채점으로 넘어가는 체감 — 불명, 추정. 빈 대기 시간을 없애 리듬 유지).

## 4. 규칙과 점수

- **점수 단위 = HP(하트) 5개** [확정: 5번 맞으면 탈락]. 내부 점수는 `misses`(누적 피격 수, 0~5).
- **감산 조건(망치 1대 = HP −1)** [확정]: 라운드에서 (a) 순서 중 하나라도 틀림, (b) 아무것도 입력 안 함 / 시간 내 미완료. 라운드당 최대 1대 (불명 — 추정: 여러 개 틀려도 1대).
- **가산 없음**. 정답은 HP 유지.
- **탈락**: misses == 5 → 즉시 탈락, 이후 라운드 참가 불가(교실 뒤에서 `sleep`).
- **승리 판정** [확정]: 최후 생존자 1명이면 그 사람 승리. 5라운드 종료 시 misses 최소 승리.
- **동점** [추정 — 2차 검증에서 GamesRadar 원문은 "beat the CPU 5 times in a row"라고만 적혀 있고 "or tie" 문구는 확인되지 않음. Serebii의 해금 조건 "5 games in a row with no losses"(패배만 없으면 됨)가 무승부 존재를 간접 시사할 뿐] → 동일 misses는 **공동 순위**, 추가 타이브레이크 없음(출처 어디에도 타이브레이크 규칙이 없으므로 임의 규칙을 넣지 않는다). 셸 `result()` 점수(정수, 클수록 좋음): 생존자 `100 + (5 - misses) * 10`, 탈락자 `eliminatedRound * 10`(1~5라운드 → 10~50, 늦게 탈락할수록 높음). 생존자는 항상 탈락자보다 위. 같은 라운드 탈락자는 공동. `text`에는 "HP n/5 · 피격 m회"를 표시. `lowerIsBetter` 없음.
- **원작 점수 예시**: 5라운드 종료 결과 예 — 1P 5/5 HP(0 miss) 1위, 2P 3/5(2 miss) 2위, COM 1/5 3위, COM 탈락(5 miss, R4에서 탈락) 4위.

## 5. 난이도 곡선

- **라운드 길이**: 4→6→8→10→12 [확정]. 인간 기억 한계(7±2)를 R3부터 넘김 — 이것이 "가장 어려운 미니게임"인 이유.
- **표시 속도**: 불명 — 추정 0.60/0.55/0.50/0.45/0.40s 개당(노래 템포가 조금씩 빨라지는 느낌).
- **입력 제한시간**: 위 `1.0s×n + 2s`. 5라운드 모두 동일 비율.
- **COM 난이도** (원작 Easy/Normal/Hard + 비밀 Hyper [확정]; Very Hard는 스타디움 2 명칭 — 셸 호환 위해 5단계 정의):
  - 핵심 변수는 **한 라운드에서 순서를 정확히 재현할 확률**과 **입력 속도**. Easy는 R3 이후 거의 항상 실수, Hyper는 거의 완벽.
  - 수치는 §8.

## 6. 화면 구성

- **카메라**: 정면(교실 앞에서 학생들을 바라보는 시점), 약간 위에서 내려다봄. 횡스크롤/탑다운 아님.
- **배치 (960×540 기준)**:
  - 칠판: 상단 중앙 `x 200~760, y 40~200`. 화살표는 칠판 안에 좌→우로 한 줄(12개까지, 폭 44px 간격), 10개 넘으면 두 줄.
  - 선생님: 칠판 왼쪽 옆 `x≈130, y≈230` (scale 1.6). 채점 때 각 학생 앞으로 걸어감.
  - 학생 4명: 하단 한 줄, `x = 180, 380, 580, 780`, `y = 400`, scale 1.0. 각각 앞에 작은 책상(갈색 rr).
  - HUD: 각 학생 머리 위 `drawPlayerTag`(1P/2P CPU…), 그 바로 아래(y≈330)에 **피격 마크 5칸**(Serebii: "marks errors above each Clefairy's head" — 원작은 머리 위에 오답 표시가 쌓임). 빈 칸=흰 ○, 맞으면 빨간 ✕로 채움(왼쪽부터). 발밑 하트는 두지 않는다(정보 중복·원작과 다름). [확정(머리 위) + 추정(모양)] 입력 단계에 각 학생 위에 진행 점(●○○○: 입력한 개수/총 개수). 타임 바는 칠판 아래 `y 210` 가로 바.
  - 좌상단 "라운드 N / 5", 중앙 자막(메시지 1.2s).
- **배경/색감**: 크림색 벽(`palette.cream`), 나무 바닥, 창문 2개(하늘색), 초록 칠판, 분홍 톤 학생(플레이어 색). 전체적으로 파스텔 유치원 느낌. 입력 단계엔 벽을 살짝 분홍(`#FFE0EC`)으로 바꿔 긴장감.

## 7. 연출

- **시작**: 셸의 Ready?/Go! 이후 선생님이 지시봉으로 칠판을 두드리며 "잘 보세요~" 자막, `sfx.count`.
- **보여주기**: 화살표 1개씩 그려질 때 `sfx.tap` + 방향별 beep(§3), 선생님이 지시봉을 그 방향으로 휘두름, 칠판 화살표는 0.15s 동안 스케일 1.3→1 팝. 원작의 "Clefairy! Clefairy!" 노래는 beep 멜로디로 대체.
- **지우기**: 지우개 사각형이 좌→우로 스윕하며 화살표 페이드.
- **입력 성공(개별 키)**: 플라밍고가 방향 포즈로 0.25s, 발밑에 화살표 글리프 잔상 0.3s.
- **라운드 채점**:
  - 오답자: 선생님이 0.3s 만에 앞으로 이동 → 망치 내려침 `sfx.hit` → 학생 `hit` 0.3s 후 `dizzy` 0.6s, 머리 위 ★ 파티클, 하트 하나가 회색으로 깨짐(`sfx.bad`). 텍스트 "땡!"
  - 정답자: `fly` 0.6s + "정답!" 텍스트, `sfx.good`.
  - 탈락: 하트 0 → `sleep`, "탈락…" 자막, `sfx.lose`.
- **종료**: 최후 1인 또는 R5 후 → 선생님이 손뼉, 승자 `fly` 반복 1.2s, `sfx.win` → `g.finish()`.
- **아나운서 대사 요지**(원작 Kids Club 아나운서, 자막으로 대체): "선생님이 그리는 순서를 잘 외우세요!" / "이제 따라 해 보세요!" / "아이고, 맞았네요!" / "마지막 라운드! 12개나 됩니다!" / "승자는 ○P!"

## 8. AI 행동 모델 (COM)

라운드 시작 시 COM별로 "이번 라운드 성공 여부"를 확률로 굴리고, 실패라면 몇 번째에서 틀릴지(균등 1..n) 정한다. 입력은 `erase` 끝 뒤 `reaction` 지연 후 `perKey` 간격으로 한 개씩 넣는다.

| 난이도 | 반응 지연 reaction(ms) | 키 간격 perKey(ms) | 개당 정확도 p_key | 라운드 성공률 (n=4/6/8/10/12) | 무입력(시간초과) 확률 |
|---|---|---|---|---|---|
| Easy | 900±300 | 700±200 | 0.85 | 0.52/0.38/0.27/0.20/0.14 | 8% |
| Normal | 600±200 | 500±150 | 0.92 | 0.72/0.61/0.51/0.43/0.37 | 3% |
| Hard | 400±150 | 380±100 | 0.95 | 0.81/0.74/0.66/0.60/0.54 | 1% |
| Very Hard(셸 호환용, 원작 없음) | 300±100 | 300±80 | 0.975 | 0.90/0.86/0.82/0.78/0.74 | 0% |
| Hyper | 200±50 | 220±50 | 0.99 | 0.96/0.94/0.92/0.90/0.89 | 0% |

- 라운드 성공률 = p_key^n. 라운드가 길수록 자동으로 실패가 늘어 원작의 "후반에 COM도 우수수 맞는" 느낌을 낸다. [미확인 — 2차 검증에서 GamesRadar 원문에 이 문장이 없었음(검색 요약의 환각 가능성). 다만 StrategyWiki "hardest of the mini-games"와 12개 기억이라는 과제 특성상 COM도 후반에 자주 틀리는 편이 자연스러워 하향치를 유지] → 이 게임은 원작에서도 COM이 약한 편이라 Hard까지는 12개 라운드 성공률을 0.6 아래로 잡았다(초판 표는 Hard 0.74로 지나치게 강했음 — 하향 조정).
- 원작은 COM 3명이 **모두 같은 난이도**(Kids Club 설정값). 셸에 난이도 선택이 없으면 **3명 모두 Normal**로 두고 COM별 p_key에 ±0.01 개체차만 준다(섞어 배정하지 않음). 사람 수가 4명이면 COM 없음.
- 실수 위치를 시각화: 틀리는 키에서 플라밍고가 엉뚱한 방향 포즈를 취한다(플레이어가 눈치챌 수 있음).
