# sushi — 「초밥 뷔페」 (원작: Sushi-Go-Round / ベロリンガのぐるぐるずし, Pokémon Stadium 1 · N64, 1999/2000 — 일본판 명칭은 「ポケモンスタジアム2」, 일본어 출처의 '스타디움2'는 같은 게임)

> 이 문서만 보고 재구현할 수 있도록 쓴 설계 스펙. 확정 수치는 출처를 달았고, 출처가 침묵한 항목은 **「불명 — 추정: …」**으로 표기했다. 셸 계약(CONTRACT.md)의 4슬롯·`up down left right a b`·플라밍고 포즈 세트를 전제로 한다.

## 1. 한 줄 요약 · 등장 캐릭터와 플라밍고 대체안

**한 줄 요약**: 회전초밥 레일 **안쪽**에 선 4마리가 60초 동안 지나가는 접시를 혀(A 버튼)로 낚아채 먹고, **먹은 초밥의 합계 금액(¥)** 이 가장 큰 플레이어가 승리. 같은 종류를 연속으로 먹으면 배율(×2→×5)이 붙고, 뜨거운 차(あがり)·와사비 든 고급 초밥을 먹으면 잠시 폭주해 조작 불능.

| 원작 요소 | 원작 설명 | 플라밍고 대체안 |
|---|---|---|
| **Lickitung(내루미) ×4** | 각 플레이어 캐릭터. 긴 혀를 뻗어 초밥을 먹음 | **플라밍고 ×4**(플레이어 색). 평상시 `idle`, 이동 `run`, 혀 뻗기 = **부리를 앞으로 길게 뻗는 연출**(`eat` 포즈 + 부리 끝에서 접시 방향으로 분홍 선/혀를 canvas로 그려 리치를 표현), 먹는 순간 `eat`, 폭주(와사비/차) `dizzy`(붉게/초록으로 틴트 + 무작위 방향으로 `run`), 승자 `jump`/`fly`, 패자 `sleep` |
| 초밥 접시 8종 | あがり(차)·かっぱ·たまご·てっか·いくら·えび·とろ·うに | 그대로 접시 8종. 접시 위 그림은 단순 색 도형(§6 표 참고). 플라밍고 세계관 맞추려면 명칭만 「새우 → 새우」, 「우니 → 성게」 등 한국어 표기 |
| 板前(주방장) | 레일 밖 상단에서 새 초밥을 올리고 「えび一丁!」 등을 외침 | **모자 쓴 플라밍고 주방장**(`idle`, 흰 모자·앞치마를 사각형으로 덧그림). 고급 초밥 투입 시 `jump` 1회 + 말풍선 텍스트 |
| 혀(舌) | 리치가 꽤 길고, 뻗는 데 약간의 시간이 걸림. 다른 Lickitung 몸에 막힘 | 분홍 굵은 선을 부리에서 목표 방향으로 `reach`px까지 애니메이션. 다른 플라밍고 몸(원 충돌)에 닿으면 거기서 멈춤 |
| 계산서(お会計) | 각자 먹은 금액이 ¥로 누적 | HUD의 「₩」 또는 「¥」 금액. 셸 result()의 `scores`에 그대로 넣음 |

## 2. 인원 · 시간 · 라운드 구조

- **4인 동시 플레이**(사람+CPU 임의 조합). 셸 규칙대로 항상 4슬롯 생성. [Bulbapedia, 신뢰 0.9]
- **제한 시간 60초**(「試合時間は1分」) [kumanote, 0.85]. 셸 `duration: 60`.
- 단판 라운드, 연장 없음. 시작 전 **초밥 8종과 가격을 보여주는 메뉴판 화면**이 원작에 있음(「Before the game begins, you are shown the eight types of sushi along with their price」) → 우리는 셸 타이틀의 `howto` 3줄에 가격을 넣고, 게임 시작 직후 1.5초간 화면 상단에 가격표 오버레이를 띄워 대체(§7).
- 종료 조건: 타이머 0. 타이머 0이 되는 순간 이미 뻗어 있던 혀가 접시에 닿으면 **인정**(불명 — 추정: 관대하게 처리, 셸 `finish` 직전 프레임까지 판정).

## 3. 조작

| N64 | 원작 기능 | 우리 액션 | 비고 |
|---|---|---|---|
| Control Stick | 레일 안쪽 원형 바닥을 8방향 자유 이동 | `up/down/left/right` (`axis()` 사용, 대각선 정규화) | 홀드. 이동 속도 §5 |
| **A** | 혀 뻗기(먹기). 바라보는 방향으로 혀가 늘어나 접시 위 초밥에 닿으면 먹음 | `a` | **단발(hit)**. 뻗는 중엔 재입력 무효. 헛스윙 시 회수까지 잠김(시간 손실 = 원작 「空振りは時間も値段もロス」) |
| B / C버튼 | 기능 없음(출처 어디에도 언급 없음) | `b` = 없음 (불명 — 추정: A와 동일 취급하지 않음, 무시) | |
| 이동 + 다른 플레이어 | 몸으로 밀 수 있음(「横からベロリンガを押す」) | 원 충돌 + 밀어내기 | 상대가 혀를 뻗는 순간 밀어 조준을 빗나가게 하는 것이 원작의 핵심 테크닉 |

**혀(Tongue) 규칙 — 수치는 추정(원작 영상 기준으로 튜닝 권장)**
- 방향: 마지막 이동 방향(정지 중이면 마지막 향한 방향). 초기값은 각자 정면 레일 쪽(§6).
- 리치 `reach = 150px`(우리 960×540 기준, 레일 폭을 넉넉히 넘김: 「意外と舌のリーチは長い」).
- 타이밍: 뻗기 **0.18s**, 끝에서 머무름 **0.06s**, 회수 **0.18s** → 헛스윙 총 락 **0.42s**. 접시에 닿는 순간 회수 시작(성공 시 락 ≈ 0.25s).
- 판정: 혀 끝 원(r=14)이 **초밥이 놓인 접시**(빈 접시 제외)의 원(r=18)과 겹치면 즉시 먹음. 혀 선분이 다른 플라밍고 몸(r=22)과 교차하면 그 지점에서 멈춤(가로채기 실패).
- 혀 뻗는 중엔 이동 불가(불명 — 추정: 원작에서 뻗는 동안 제자리).
- 접시가 **움직이는 표적**이므로 「조금 앞을 겨냥」해야 함(원작 팁). 이걸 자연스럽게 만들려면 혀 끝은 이동 방향으로 직선, 접시는 레일 속도로 계속 이동.

가격 8종은 일본어 검색 요약·kumanote·serebii·GameFAQs 게시판이 모두 일치 [신뢰 0.9]. 확률은 「安い皿の方が回ってくる確率が高め」 외 수치 없음 → 위 분포는 추정.

**콤보(연속 같은 종류)** [kumanote 0.85, StrategyWiki 0.8]
- 같은 종류를 연속으로 먹으면 그 접시 금액이 **×2 → ×3 → ×4 → ×5(최대)**. 첫 접시 ×1, 2번째 ×2, 3번째 ×3, 4번째 ×4, 5번째 이후 ×5 유지.
- 다른 종류를 먹으면 ×1로 리셋. **차(あがり)·와사비 초밥을 먹어도 리셋**(원작 팁 「コンボを切る」). 헛스윙은 리셋하지 않음(불명 — 추정).
- 예: 계란 5연속 = 150+300+450+600+750 = **¥2,250**. 우니 1개 = ¥1,000이지만 상대에게 뺏기면 **¥2,000 차이**(원작 팁).
- 차도 콤보 대상인지: 불명 — 추정: 아니오(폭주로 리셋).

**와사비**(고급 초밥 ebi/toro/uni 중 일부에 숨어 있음)
- 겉으로 구분 불가. 확률: 불명 — 추정 **25%**. 먹으면 금액은 **정상 가산**(원작 설명은 "폭주"만 언급, 감산 언급 없음)하되 콤보는 끊기고 **폭주 2.0s**.
- 폭주(暴走): 조작 불능, **원을 그리며** 빠르게 뛰어다님(「熱さで暴れて制御不能」·「run around out of control for a few seconds」·accordionsprout 「run around in circles while screaming」 — 무작위 방향 지그재그가 아니라 제자리 근처를 빙글빙글 도는 원운동). 지속 **2.0s**(불명 — 추정, "a few seconds"; 1.5~3.0s 튜닝 범위). 폭주 중 다른 플레이어를 밀 수 있음. **연출 색 구분(2차 비평가 확정)**: ¥20 찻잔(서양 출처는 이 컵을 'wasabi cup'이라 부름) = **빨강 틴트+비명**, 고급 초밥에 숨은 와사비 = **초록 틴트+구역질**.

**감산·페널티**: 없음(금액이 줄어드는 일 없음). 페널티는 전부 **시간 손실**(헛스윙 0.42s, 폭주 2s, 콤보 리셋).

**승리 판정**: 60초 후 합계 ¥ 최대. **동점**: 원작 불명 — 추정: 공동 순위(셸이 같은 점수를 같은 등수로 표시). 원작 점수대 예시: 보통 플레이 ¥3,000~¥6,000, CPU 포함 고회전 게임에서 ¥8,000~¥12,000(「値段もインフレ」). result(): `{scores:[bill0..bill3], text:'가장 비싼 계산서!'}`.

**접시 보충(Plate refill)** [kumanote 0.85]
- 레일 위 접시 슬롯은 **12개**(GameFAQs 미니게임 가이드 「twelve random types of sushi appear on a rotating counter」[0.75], 등간격). ~~추정 16개~~ → 비평가 수정. 먹은 자리는 **빈 접시**가 되어 계속 돌고, 비워진 뒤 **약 5초 미만(4.5s)** 후 주방장이 새 초밥을 올림. 주방장 위치(상단 중앙)를 지나는 빈 접시에 채우는 방식이 아니라 **타이머 기반**으로 그 자리에 등장(원작은 슬롯 어디에서든 「空き皿に出てきた瞬間」 등장) → 추정: 빈 접시가 4.5s 경과 후 다음 프레임에 그 자리에서 새 초밥 팝업.
- 새우 이상 고급이 올라갈 때 주방장 「새우 하나!」 말풍선 + `sfx.pop`.
- 시작 시 12슬롯 전부 **무작위**로 채움(원작 「twelve random types」— 정면 보정 없음). 「정면 3접시 정도를 보고 스타트 대시」가 정석이므로 보정은 넣지 말고 확률표대로만 굴린다(비평가 수정: 정면 보정 삭제).

## 5. 난이도 곡선 · CPU 난이도

**시간 곡선**: 원작에서 레일 속도가 시간에 따라 빨라진다는 기록 없음. 「寿司の回転が速い」는 **레일 속도가 아니라 접시가 소비되어 보충되는 회전율** 이야기 → 레일 속도 **일정**. 난이도는 CPU 강도와 「먹을수록 비싼 초밥 출현 기회 증가」로 자연 발생.
- 레일 속도: 불명 — 추정 **한 바퀴 20s**(둘레≈1,900px → **95px/s**). 12슬롯이면 접시 간격 ≈158px, 한 자리에 서 있으면 **약 1.7s마다 접시 하나**가 지나감 — 이 리듬이 원작 「접시 앞을 조금 겨냥」 감각의 기준. 방향: 불명 — 추정 **시계 방향**(위에서 보아).
- 플레이어 이동 속도: 추정 **170px/s**. 폭주 중 **260px/s**.

**CPU 난이도 (Easy / Normal / Hard / +Hyper 해금)** — 원작 관찰 [kumanote]: CPU는 「초밥이 표시되기 전부터 최속으로 그쪽으로 이동」(미래예지), 그러나 「우니가 옆에 있어도 남의 계란을 먹으러 가는」 불가해한 행동도 있음. 「닥치는 대로 먹는 경향」 → 접시 회전율↑ → 인플레.
원작의 난이도(よわい/ふつう/つよい + 숨김 すごい=Hyper)는 **COM 전원에 공통으로 적용되는 단일 설정**이며 슬롯별로 섞이지 않는다(Bulbapedia/gfinity, 0.85). Hyper 해금: 「Who's the Champion?」을 Hard로 5연승. 셸에는 난이도 선택이 없으므로 **CPU 전원 Normal**을 기본으로 하고, 원작 느낌을 위해 슬롯별 혼합은 하지 않는다(비평가 수정). 수치는 §8.

## 6. 화면 구성

- **카메라**: 약간 기울어진 탑다운(원작은 3D 비스듬 시점). 우리는 **정면 탑다운 2.5D**: 레일을 타원 링으로 그림.
- **레일**: 화면 중앙의 타원 링. 우리 좌표(960×540): 중심 (480, 290), 바깥 반경 rx=400/ry=215, 안쪽 반경 rx=330/ry=155(폭 ≈ 70px). 링 색: 원목 갈색(#B98A55)에 회색 벨트(#8E8E8E) 띠. 접시는 링 중앙선 위를 따라 이동.
- **플레이어 초기 위치**: 링 **안쪽** 바닥(연회색 타일 #E9E4D8)에 4방향 배치. 1P 아래(480,405), 2P 오른쪽(690,290), 3P 위(480,175), 4P 왼쪽(270,290). 초기 방향은 각자 정면 레일 쪽. 안쪽 바닥 안에서만 이동 가능(타원 안 clamp).
- **주방장**: 링 밖 상단 중앙(480, 40) 카운터 뒤. 말풍선은 그 위.
- **HUD**: 네 모서리에 각 플레이어 카드 — `drawPlayerTag` + 금액 「¥1,250」(굵은 흰 글씨, 검은 외곽선) + 현재 콤보 「×3 계란」(금색). 1P 좌하, 2P 우하, 3P 우상, 4P 좌상(원작 계산서 위치 불명 — 추정). **타이머**: 상단 중앙(주방장 옆, 480,90)에 「남은 시간 42」 큰 숫자, 10초 이하 빨강 + `sfx.tick`.
- **접시 그리기**: 흰 원 접시(r=18, 테두리 회색). 위에 초밥은 색 도형 — **원작 외형(GameFAQs 가이드의 묘사, 0.75)** 기준: 차=**초록 찻잔**(원기둥), 오이말이=**검정(김) 바탕에 흰 원 2개 + 초록 심**, 계란=**노란 윗면 + 흰 밥 + 검은 김 띠**, 참치말이=**검정 바탕에 흰 원 2개 + 분홍 심**, 연어알=**빨강/주황 윗면 + 검정(김) 아랫면**, 새우=**주황/흰 줄무늬 새우 모양**, 뱃살=**빨강 윗면 + 흰 밥**, 성게=**주황 윗면 + 검정(김) 아랫면**. 빈 접시는 흰 원만. 접시 자체 색은 원작 불명 — 고급(≥¥350) 접시 테두리 금색은 우리 추가(추정). 말이류(오이·참치)는 「흰 원 2개」로 그려야 원작과 같은 실루엣.

## 7. 연출

- **시작**: 셸의 "준비… 시작!" 카운트 뒤 첫 1.5s 동안 상단에 반투명 가격표 띠(8종 아이콘+가격) 표시 후 페이드아웃. 원작은 별도 메뉴 화면 → 압축 대체.

## 8. AI 행동 모델 제안

CPU는 **후보 접시 평가 → 목표 지점으로 이동 → 접시가 리치 안에 들어오는 시점에 A** 의 루프. 원작 특성(스폰 미래예지, 가끔 비합리적 선택, 닥치는 대로 먹기)을 파라미터로 표현.

## 비평가 보강

독립 확인 출처: Bulbapedia(Sushi-Go-Round 항목 본문·난이도 절), StrategyWiki(curl 본문), kumanote(일본어 실플레이 공략), serebii Kids Club, GameFAQs 미니게임 가이드(JosiahIsBack, 검색 요약 경유 — 본문 403), gfinity(난이도 해금), accordionsprout. 아래는 **수정**(위 본문에 인라인 반영) 과 **추가**.

### 수정한 것
1. **접시 슬롯 수 16 → 12.** GameFAQs 가이드 「When the game starts, twelve random types of sushi appear on a rotating counter」. §4·§6 반영. 12슬롯 × 95px/s = 약 1.7s마다 접시 1개가 지나가는 리듬.
2. **시작 배치는 완전 무작위.** 「정면 3슬롯 보정」은 원작에 없는 우리 발명이므로 삭제. 초반 스타트 대시의 운 요소도 원작의 일부.
3. **CPU 난이도는 전원 공통.** 원작 Easy/Normal/Hard(+Hyper)는 COM 3명 모두에 적용되는 단일 설정. 슬롯별 `[Normal, Hard, Easy]` 혼합안 폐기 → **전원 Normal** 기본. Hyper는 「Who's the Champion?」 Hard 5연승으로 해금되는 숨김 단계(Bulbapedia/gfinity).
4. **초밥 외형을 원작 묘사대로 교정.** 성게=주황 윗면+검정 아랫면(겨자색 아님), 뱃살=빨강 윗면+흰 밥(분홍 아님), 연어알=빨강 윗면+검정 아랫면, 말이류는 「검정 바탕에 흰 원 2개+심(초록/분홍)」, 차=초록 찻잔. 출처: GameFAQs 「Orange topped, black bottomed – 1000 / Red topped, white bottomed – 600 / Shrimp looking – 350 / Red top, black bottom – 250 / 2 white circles with pink centre, black bottomed – 200 / Yellow topped, white bottomed, black lined – 150 / 2 white circles with green centre – 50」.
5. **일본판 명칭 혼동 주의**: 일본어 출처의 「ポケモンスタジアム2」는 서양판 Pokémon Stadium 1과 같은 게임. 스펙 제목의 "Stadium 1" 표기는 맞음.

### 추가한 것(확인된 사실)
6. **와사비 먹어도 금액은 전액 가산 확정.** GameFAQs 팁 「Eat orange and black cakes, they are poisoned but they're worth $1000」 — 성게에 와사비가 들어 있어도 ¥1,000은 들어온다. §4 「정상 가산」 추정 → 확정(0.75).
7. **폭주 연출의 두 계열**: (a) 차·와사비 = 몸이 **빨개지며** 비명 지르고 마구 뛰어다님(「immediately turn Lickitung red and send him screaming until he cools down」, serebii 「speed up and run off, with no control」), (b) 일부 초밥은 **초록빛 구역질**(accordionsprout 「turn Likitung green and cause nauseous animations」). 우리 구현(2차 비평가 확정): **¥20 찻잔 = 빨강 틴트(서양 출처 'wasabi cup turn red'·serebii '¥20 lowest item = wasabi')**, **고급 초밥 속 와사비 = 초록 틴트+구역질('sushi rolls turn green and nauseous')**. 둘 다 `dizzy` + 원운동 `run`(260px/s), 조작 불능·콤보 리셋·지속 2.0s는 동일. Bulbapedia의 「slow Lickitung down」은 '조작을 못 해 결과적으로 느려진다'는 뜻으로 해석 — 이동 속도를 줄이는 게 아니라 **조작 불능**이 맞다(serebii·cheatcodes·kumanote 3곳 일치).
8. **콤보는 「같은 종류를 2번 이상 연속」에서 시작**(GameFAQs 「if a player eats the same type of sushi more than once, the price doubles」) — §4의 첫 접시 ×1, 2번째 ×2 규칙과 일치. 상한 ×5(kumanote). 핵심 밸런스 팁(GameFAQs 가이드): 「200 × 5 is just as good as 1000 and MUCH more common」 → CPU Normal 이상은 콤보 유지 선호를 실제로 켜야 원작 CPU의 점수대가 나온다.
9. **영어판 화폐 표기**: 영어판은 「P」(포켓달러 기호)로 P20~P1000, 일본판은 ¥. 우리는 화면에 「¥」를 쓰되 셸 result.text 등에서 통화기호 하나로 통일. Bulbapedia: 시리즈 중 돈이 등장하는 유일한 미니게임.
10. **게임 종료 = 타이머 0 단 하나.** 탈락·조기 종료·연장 없음(모든 출처 일치). 셸 `duration: 60` 고정, `finish()` 직접 호출 없음.
11. **B 버튼 무기능 확정에 가까움**: Bulbapedia·serebii·kumanote 모두 「스틱 이동 + A 먹기」만 기술. `b`는 무시.
12. **HUD 필수 정보**: 항상 4명의 계산서 금액이 보여야 하며(계약), 원작도 각 플레이어의 누적 금액을 상시 표시. 콤보 배율 표시는 우리 편의 추가(원작 화면에 배율 숫자가 항상 떠 있다는 근거 없음 → 접시를 먹을 때 「×3」 팝업으로만 보여도 됨; 상시 표시는 선택).

### 2차 검증 (독립 재확인, 2026-09-10)
재확인 출처: Bulbapedia Sushi-Go-Round 본문 + 시리즈 미니게임 페이지 난이도 절, StrategyWiki(curl 본문), kumanote 본문, serebii Kids Club, accordionsprout, cheatcodes 가이드. GameFAQs 가이드(50319)는 403으로 여전히 본문 미확인 → 「12접시」는 검색 요약 의존(0.75) 유지, 빌드 시 12 고정하되 상수로 빼 둘 것. 검색 예산 소진으로 추가 검색 불가.

**수정(인라인 반영)**
13. **폭주 연출 색이 §4·§7·#7에서 서로 어긋나 있던 것 통일.** 확정: ¥20 찻잔 = 빨강(비명), 와사비 초밥 = 초록(구역질). serebii는 ¥20 최저가 아이템 자체를 「a bit of wasabi」로 부르고 accordionsprout는 「wasabi cups → red」「some sushi rolls → green nauseous」라 하므로, 일본어 출처의 「あがり(차)」= 서양 출처의 「wasabi cup」이 같은 ¥20 컵이다. cheatcodes 「item with a green center is tea」 → 컵 자체는 **초록 찻잔** 외형이 맞음.
14. **폭주 이동 패턴 = 원운동.** 「run around in circles while screaming」. 무작위 방향 지그재그 대신 반지름 40px 원을 빙글빙글 돌게 하면 원작 느낌. 다른 플레이어와 충돌 시 밀어냄 유지.

**추가(확인·결정)**
15. **동점 처리 확정에 가까움**: Bulbapedia 「Rock Harden is the only mini-game where players don't get points if they tie」 → Sushi-Go-Round은 동점 시 **공동 순위로 양쪽 모두 승점**. 셸 result()에 같은 점수 그대로 넣으면 셸이 공동 등수로 표시(0.8).
16. **레일은 "천천히" 돈다**(accordionsprout 「trays rotate slowly」·「timing licks correctly is essential」). 20s/바퀴(95px/s) 추정을 뒷받침. 빠르게 튜닝하지 말 것 — 원작의 리듬은 「접시가 눈앞을 지나는 1.7s 창 안에 조준」이며, 난이도는 속도가 아니라 자리 싸움·콤보 선택에서 나온다.
17. **동시 조준 규칙(빌드 필수, 원작 불명 → 결정)**: 같은 접시에 두 혀가 같은 프레임에 닿으면 **플레이어 인덱스 낮은 쪽이 아니라 혀 끝이 접시 중심에 더 가까운 쪽**이 먹는다. 접시가 사라진 뒤 도착한 혀는 헛스윙(0.42s 락).
18. **밀치기 물리 수치(결정)**: 플라밍고 원 r=22, 겹치면 겹친 깊이만큼 두 몸을 반씩 밀어내고(혀 뻗는 중인 쪽은 그래도 밀림 — 원작 「横から押す」 테크닉 성립), 폭주 중인 몸은 2배 힘. 밀린 몸도 안쪽 바닥 타원 안으로 clamp.
19. **혀 뻗는 중 방향 고정**: 발동 순간의 향하는 방향으로 직선 고정(축 입력으로 도중 회전 불가). 「タイミング」이 핵심이라는 출처 일치.
20. **차는 콤보 대상 아님·와사비는 금액 가산**(#6과 함께): 차 ¥20도 계산서에 가산되지만 배율 리셋 + 폭주. CPU Easy가 차를 먹는 것은 원작 CPU의 비합리 행동 재현.
21. **시작 연출**: 원작은 메뉴판(8종+가격) 화면 후 주방장 외침으로 시작 → 우리는 셸 카운트다운 후 1.5s 가격표 오버레이 + 「많이 드세요!」 말풍선. 종료는 주방장 「계산이요!」(accordionsprout 「shouting sushi chef announces start/end」).
22. **HUD 상시 표시**: 4명 금액 상시(계약). 콤보 배율은 상시 표시로 결정(원작 불명이지만 CPU가 콤보를 노리는 게 보여야 플레이어가 「끊기」 전략을 쓸 수 있음).

**여전히 불명(변경 없음)**: 레일 방향(시계), 8종 확률, 와사비 확률 25%, 폭주 2.0s, 혀 프레임 수치, 헛스윙 콤보 유지, CPU 내부 수치, 12접시(요약 의존).
