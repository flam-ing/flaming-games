# 무한계단 플라밍고 🦩

끝없이 이어지는 지그재그 계단을 오르는 클래식 **무한계단** 스타일 아케이드 게임입니다.
한 발짝만 헛디뎌도, 체력이 바닥나도 게임 오버! 플라밍고와 함께 새벽 → 낮 → 노을 → 밤으로 물드는 하늘을 오르세요.

**▶ 플레이하기: <https://flam-ing.github.io/flaming-games/flamingo-stairs/>**

## 게임 방법

- 계단은 한 칸 위로 이어지거나, 방향이 꺾여 반대쪽으로 이어집니다.
- 다음 계단이 있는 방향으로만 올라야 합니다. 없는 곳을 디디면 추락합니다.
- 상단의 체력 게이지는 계속 줄어들고, 올바르게 오를 때마다 조금씩 회복됩니다. 점수가 오를수록 더 빨리 닳아요.
- 50계단마다 마일스톤 축하 효과(색종이 + 차임)가 터지고, 하늘 팔레트가 점점 변합니다.
- 최고 기록은 브라우저에 자동 저장됩니다.

## 조작

| 동작 | 키보드 | 터치 |
|---|---|---|
| 오르기 (바라보는 방향으로 한 칸) | `Space` `↑` `W` `X` | 화면 오른쪽 버튼 |
| 방향전환 (방향을 뒤집고 한 칸) | `Shift` `←` `→` `A` `D` `Z` | 화면 왼쪽 버튼 |
| 다시하기 | `Space` / `Enter` | 다시하기 버튼 |
| 음소거 | — | 우측 상단 스피커 버튼 |

## 특징

- 새벽 → 낮 → 노을 → 밤으로 부드럽게 순환하는 하늘 팔레트, 별과 달, 패럴랙스 구름·야자수 실루엣
- 코드로만 그린 벡터 플라밍고: S자 목, 검은 부리 끝, 외다리 서기, 스쿼시&스트레치 점프, 방향전환 시 깃털 휘날림, 추락 시 데굴데굴 텀블링
- WebAudio로 합성한 사운드: 콤보에 따라 음이 높아지는 스텝음, 실패음, 마일스톤 차임
- 실패 시 화면 흔들림, 점수 팝, 콤보 글로우, 착지 먼지 등 juicy 연출
- 모바일 세로 화면 최적화 (데스크톱에서는 장식 배경으로 레터박스), 레티나 대응

## 기술 스택

- **HTML + CSS + Vanilla JavaScript** 단일 파일 (`index.html`)
- **Canvas 2D** 렌더링, `requestAnimationFrame` 델타타임 루프 (로직/렌더 분리)
- **WebAudio API** 사운드 합성 — 외부 라이브러리·외부 에셋 0개
- `localStorage` 최고 기록/음소거 설정 저장
- GitHub Pages로 배포되는 정적 페이지
