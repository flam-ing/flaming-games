# 🦩 플라밍고 대군단 (Flamingo Gate Defense)

광고에서 한 번쯤 본 그 게임! 수학 관문을 골라 플라밍고 군단을 불리고, 트랙을 가로막는 악어·하이에나·멧돼지·뱀 무리를 숫자로 밀어붙이는 3D 하이퍼캐주얼 러너 디펜스입니다.

**▶ 플레이: https://flam-ing.github.io/flaming-games/flamingo-gate-defense/**

## 게임 방법

- 플라밍고 군단이 자동으로 달립니다. 좌우로 움직여 관문을 선택하세요.
- **파란 유리 관문** = 군단 증가(`+N`, `×2`, `×3`), **빨간 유리 관문** = 감소(`−N`, `÷2`).
  - 가끔은 양쪽 다 나쁜 관문! 덜 나쁜 쪽을 고르세요.
- 트랙 위의 **적 무리**와 부딪히면 1:1로 숫자가 소멸합니다. 내 숫자가 더 크면 생존자가 계속 달립니다.
- 몇 번의 전투마다 거대한 **보스**가 등장합니다. 큰 HP 숫자를 깎아내세요.
- 군단이 0마리가 되면 게임 오버. 점수 = 거리(m) + 웨이브 클리어 보너스.

## 조작

| 입력 | 동작 |
|---|---|
| 마우스 드래그 / 터치 드래그 | 좌우 이동 |
| `←` `→` 또는 `A` `D` | 좌우 이동 |
| 클릭 / 탭 / `Space` / `Enter` | 시작 · 다시하기 |
| 우상단 🔊 버튼 | 소리 켜기/끄기 (저장됨) |

## 기술 스택

- **Three.js r160** (importmap, unpkg CDN) — 단일 `index.html`, 빌드 없음
- `THREE.InstancedMesh` 군중 렌더링 (군단·적 무리·잔해), 오브젝트 풀링 (관문·웨이브·파티클)
- 버텍스 컬러 로우폴리 프로시저럴 모델 (플라밍고·악어·하이에나·멧돼지·뱀·야자수·섬)
- WebAudio 신스 사운드 (관문 차임·전투 굉음·보스 혼·패배 스팅) — 오디오 파일 없음
- 로컬 스토리지 최고 기록 저장 (`flamingo-gate-defense-best`)
- 정적 페이지 — GitHub Pages에서 바로 동작
