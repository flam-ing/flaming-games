# 🦩 플라밍고 체스 — Flamingo vs Black Swan

진주빛 플라밍고 진영과 흑요석 흑조 진영이 맞붙는 **프리미엄 3D 체스**입니다.
단일 `index.html` 파일 하나로 동작하는 정적 웹 게임으로, Babylon.js의 PBR 렌더링과
chess.js의 완전한 체스 규칙 엔진 위에서 만들어졌습니다.

**▶ 바로 플레이:** https://flaming-games.vercel.app/flamingo-chess/

---

## 특징

- **플라밍고 vs 흑조** — 모든 기물이 목이 긴 새의 실루엣으로 조각되어 있습니다.
  - 폰 = 머리를 웅크린 새끼새 · 룩 = 둥지 탑 위의 새 · 나이트 = S-커브 목의 옆얼굴
  - 비숍 = 곧게 세운 긴 목(주교모자 부리) · 퀸 = 티아라 + 활짝 편 한쪽 날개 · 킹 = 왕관 + 가장 큰 키
- **고급 렌더링** — PBR 재질(클리어코트·시인성 광택·흑조 이리데선스), 노을 하늘 돔 기반
  IBL(ReflectionProbe), 블룸 + FXAA + ACES 톤매핑 + SSAO + 비네트, 부드러운 그림자,
  프로시저럴 대리석 보드(로즈 + 아이보리), a–h/1–8 좌표가 새겨진 금장 프레임
- **완전한 체스 규칙** (chess.js) — 캐슬링, 앙파상, 승격(4지선다 픽커),
  체크 표시, 체크메이트/스테일메이트/3회 동형반복/50수 규칙/기물 부족 무승부
- **AI 대국** — 미니맥스 + 알파-베타 가지치기 + 기물 위치 테이블.
  Web Worker(Blob)에서 실행되어 UI가 멈추지 않습니다. 난이도 쉬움/보통/어려움
- **연출** — 기물 호(arc) 이동 애니메이션, 포획 시 깃털 파티클, 선택/체크 글로우,
  WebAudio 신디사이저 효과음(이동·포획·체크·승격·팡파르)
- **기록** — 기보(SAN) 패널, 포획 기물 트레이, 무르기(플레이어+AI 한 쌍),
  전적·음소거 localStorage 저장

## 조작법

| 동작 | 마우스 | 터치 |
|---|---|---|
| 기물 선택 | 기물 **좌클릭** → 이동 가능 칸에 글로우 표시 | 기물 탭 |
| 이동 (클릭) | 표시된 칸 클릭 | 표시된 칸 탭 |
| 이동 (드래그) | 기물을 **좌클릭 드래그** 후 원하는 칸에 놓기 | 기물을 드래그 |
| 카메라 회전 | **우클릭(또는 휠클릭) 드래그** | 두 손가락 |
| 확대/축소 | 마우스 휠 | 핀치 |
| 시점 초기화 | 상단 ◎ 버튼 | 상단 ◎ 버튼 |
| 무르기 | 상단 ↶ 버튼 (내 수 + AI 수 한 쌍) | 동일 |
| 음소거 | 상단 ♪ 버튼 (자동 저장) | 동일 |
| 새 게임 | 상단 ✦ 버튼 | 동일 |

> 좌클릭 드래그는 기물 전용, 카메라는 우클릭/두 손가락 — 조작이 서로 충돌하지 않습니다.

## 기술 스택

| 구성 | 내용 |
|---|---|
| 렌더링 | [Babylon.js 7.54.3](https://cdn.jsdelivr.net/npm/babylonjs@7.54.3/babylon.js) (CDN 고정 버전) |
| 체스 규칙 | [chess.js 1.0.0](https://cdn.jsdelivr.net/npm/chess.js@1.0.0/dist/esm/chess.js) (ESM, CDN 고정 버전) |
| AI | 미니맥스 + 알파-베타 + PST, Blob URL 기반 Web Worker (실패 시 메인 스레드 폴백) |
| 텍스처 | 전부 프로시저럴 (DynamicTexture 대리석·하늘·깃털) — 외부 에셋 0개 |
| 사운드 | WebAudio 오실레이터/노이즈 신디사이저 — 오디오 파일 0개 |
| 배포 | 정적 파일 1개, GitHub Pages 그대로 배포 가능 |

## 로컬 실행

```bash
python3 -m http.server 8080
# → http://localhost:8080
```

(ESM/Worker 사용으로 `file://` 직접 열기 대신 로컬 서버를 권장합니다.)

## 디버그 훅

| 훅 | 설명 |
|---|---|
| `?fen=<FEN>` | 지정 포지션으로 즉시 시작 |
| `?nosound` | 소리 끄기 |
| `?noai` | AI 자동 응수 끄기 |
| `?moves=e4,e5,Qh5` | SAN/UCI 수열 자동 적용 (AI 응수 없음) |
| `?selftest=1` | 내장 규칙 자가 테스트 실행 (`body[data-selftest]`) |
| `window.__game.move('e4' \| 'e2e4')` | 수 두기 (SAN/UCI) |
| `window.__game.state()` / `.fen()` | 상태/FEN 조회 |
| `window.__game.aiMoveNow()` | AI 즉시 착수 |
| `window.__game.setDifficulty(0~2)` | 난이도 변경 |
| `window.__game.undo()` / `.newGame(fen?)` | 무르기 / 새 게임 |
