# 🦩 점프 플라밍고 (Flamingo Jump)

두들 점프 스타일의 수직 점프 게임입니다. 열대 석호에서 출발한 플라밍고가 연잎, 구름, 꽃 점프대를 밟고 노을을 지나 별이 빛나는 밤하늘까지 끝없이 날아오릅니다. 고도가 높아질수록 발판은 드물어지고, 움직이는 구름과 부서지는 얼음이 늘어나며, 심술궂은 게가 길을 막습니다. 매운 고추를 먹으면 2초간 무적 로켓 부스터!

**▶ 플레이하기: [https://flam-ing.github.io/flaming-games/flamingo-jump/](https://flam-ing.github.io/flaming-games/flamingo-jump/)**

## 조작법

| 입력 | 동작 |
|---|---|
| `←` `→` 또는 `A` `D` | 좌우 이동 |
| 화면 좌/우 터치 (모바일) | 좌우 이동 |
| 기기 기울이기 (권한 허용 시) | 좌우 이동 |
| `Space` / `Enter` / 탭 | 게임 시작 · 다시하기 |
| `M` 또는 우측 상단 버튼 | 음소거 |

화면 밖으로 나가면 반대쪽으로 이어집니다(좌우 랩어라운드). 아래로 떨어지면 게임 오버!

## 발판 & 아이템

- 🪷 **연잎** — 기본 발판
- ☁️ **구름** — 좌우로 떠다니는 발판
- 🧊 **깨진 얼음** — 한 번 밟으면 부서짐
- 🌺 **히비스커스 꽃** — 슈퍼 점프 스프링
- 🌶️ **매운 고추** — 2초간 로켓 부스터 + 무적
- 🦀 **게** — 위에서 밟으면 처치, 옆에서 닿으면 게임 오버 (로켓 중엔 무적)

## 특징

- 고도에 따라 변하는 하늘: 열대 석호 → 복숭아빛 노을 → 보랏빛 황혼 → 달과 별이 빛나는 깊은 밤
- 코드로만 그린 벡터 플라밍오 — 점프 시 다리 접기/펴기, 스쿼시&스트레치, 날갯짓
- WebAudio로 실시간 생성되는 효과음 (외부 오디오 파일 없음)
- 패럴랙스 구름·새·야자수, 물결 파문, 깃털·불꽃 파티클
- 최고 기록 로컬 저장 (`localStorage`)

## 기술 스택

- **HTML + CSS + Vanilla JavaScript** 단일 파일 (`index.html`)
- **Canvas 2D** 렌더링, `devicePixelRatio` 대응 레티나 스케일링
- **WebAudio API** 사운드 합성
- 외부 라이브러리·에셋 없음 — 정적 페이지로 바로 동작 (GitHub Pages)

## 실행

```bash
# 아무 정적 서버로 열면 됩니다
python3 -m http.server 8080
# → http://localhost:8080
```

또는 `index.html`을 브라우저로 직접 열어도 됩니다.
