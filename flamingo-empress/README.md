# 🦩 플라밍고 여제: 홍학천하

> 몰락한 홍학 귀족의 외동딸 **홍련(紅蓮)** — 분홍 깃털로 옥좌를 물들이고 천하를 통일하라.

『성세천하: 여제의 탄생』류의 **궁정 라이프 시뮬레이션**을 오마주한 턴제 국정 운영 브라우저 게임입니다.
설치 없이 브라우저에서 바로 즐길 수 있습니다.

**▶ 지금 플레이:** https://flam-ing.github.io/flaming-games/flamingo-empress/

---

## 게임 소개

몰락 귀족에서 시작해 **남작 → 백작 → 공작 → 여왕 → 여제 → 성세천하**로 승급하며,
동물 대신들을 등용하고, 영지를 정벌하고, 매일 쏟아지는 사건을 처리해 천하통일을 이루는 게임입니다.
마지막에는 황궁 평원의 **사자 황제**와의 최종 결전이 기다립니다.

## 플레이 방법

1. **🏯 조정** 탭에서 `하루 보내기`를 누르면 하루가 지나갑니다.
   - 영지 세곡과 대신들의 녹봉 수입이 들어오고, 매일 **랜덤 사건**이 벌어집니다.
   - 사건마다 2~3개의 선택지가 있으며, 자원 변화가 표시됩니다. `❓ 숨은 결과`나 `🎲 도박수`도 있으니 신중히!
2. **📜 신하** 탭에서 동물 대신을 등용·승급하세요.
   - 부엉이 재상(국고), 거북이 학사(식량), 호랑이 대장군(군사), 공작 예조판서(민심), 여우 외교관(도박수 성공률), 두루미 어의(재난 방어), 검은 고양이 밀정(숨은 효과 간파) 등 10명.
   - **충성도**가 30 밑으로 떨어지면 배신(간신) 사건이 터질 수 있습니다. 하사품으로 달래세요.
3. **🗺️ 영지** 탭에서 징병하고 라이벌 동물 영주들을 정벌하세요.
   - 두꺼비 촌장부터 하이에나 여왕, 늑대 칸까지 — 이기면 영지 산출과 위신이 영구히 늘어납니다.
4. **👑 여제** 탭에서 승급의 길과 치세 실록을 확인하세요.
   - 위신이 차면 **승급식**이 열리고 새로운 대신·영지가 해금됩니다.

### 자원 4종

| 자원 | 설명 |
|------|------|
| 💰 국고 | 바닥나서 빚지면(**0 미만**) 폐위 |
| 🌾 식량 | 부족하면 병사들이 굶주려 이탈 |
| ❤️ 민심 | **0이 되면** 폐위 (0~100) |
| ⚔️ 군사력 | 영지 정벌의 원동력 |

- ✨ **위신**은 승급 경험치입니다. 사건·정벌로 모으세요.
- 치세는 **자동 저장**되며(localStorage), 타이틀 화면에서 `이어하기`가 가능합니다.
- 🔔 버튼으로 효과음(WebAudio)을 켜고 끌 수 있습니다.

## 기술 스택

- **순수 HTML + CSS + Vanilla JS 단일 파일** (`index.html`) — 외부 라이브러리·에셋·폰트 없음
- 모든 그래픽은 CSS 그라디언트/SVG/이모지로 코드에서 직접 렌더링 (여제 초상화는 손으로 그린 인라인 SVG)
- 효과음은 WebAudio 오실레이터 합성 (즉위 징, 동전, 전고, 차임)
- 55종 이상의 사건(희귀 연쇄 사건 포함), 대신 10명, 영지 11곳 — 전부 선언형 데이터 배열이라 쉽게 확장 가능
- 모바일 세로형 우선 레이아웃(~480px), 데스크톱에서는 궁궐 실루엣 레터박스
- GitHub Pages 등 정적 호스팅에서 그대로 동작

## 개발용 디버그 훅

| URL 파라미터 | 효과 |
|---|---|
| `?rich=1` | 후반부(여왕, 58일차) 세이브 상태로 시작 |
| `?screen=title/event/eventresult/ministers/war/warconfirm/warresult/profile/promo/ending/gameover` | 해당 화면 바로 열기 |
| `?sim=80` | 80일 자동 플레이 후 결과를 `body[data-sim]`에 기록 (밸런스 검증용) |

디버그 모드에서는 세이브를 건드리지 않으며, 런타임 오류는 `body[data-err]`로 노출됩니다.
