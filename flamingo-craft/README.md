# 🦩 플라밍고크래프트 (FlamingoCraft)

**플라밍고가 주인공인 파스텔 복셀 샌드박스.**
마인크래프트 스타일의 절차 생성 세계에서 복셀 플라밍고가 되어 민트빛 초원, 산호 라군, 야자수 해변을 탐험하고 블록을 부수고 쌓아 보세요. 낮과 밤이 흐르고, 세계는 브라우저에 자동 저장됩니다.

▶ **플레이:** https://flam-ing.github.io/flaming-games/flamingo-craft/

## 특징

- 🌍 시드 기반 절차 생성 지형 — 초원 · 모래 해변 · 돌 언덕 · 호수 · 야자수 · 꽃, 그리고 플라밍고 세계의 시그니처 **코럴 블로섬** 블록
- 🦩 복셀 플라밍고 주인공 — S자 목, 검은 부리 끝, 긴 다리, 걸을 때 뒤뚱뒤뚱 애니메이션 + 가만히 서 있으면 한 다리로 서는 진짜 플라밍고 자세
- 🌗 약 3분 주기의 낮·밤 순환 — 노을, 달, 별, 부드러운 그림자
- 🧱 9종 블록 핫바(절차 생성 텍스처 아이콘), 블록 파괴/설치 이펙트와 효과음
- 💾 수정한 블록과 위치를 localStorage에 자동 저장 (「새 세계」 버튼으로 초기화)
- 📱 모바일은 가상 조이스틱 간단 조작 지원 (키보드+마우스 권장)

## 조작법

| 키 | 동작 |
|---|---|
| `W` `A` `S` `D` | 이동 |
| 마우스 | 시점 회전 (클릭으로 포인터 잠금) |
| `Space` | 점프 / 물속에서 헤엄치기 |
| 좌클릭 | 블록 부수기 |
| 우클릭 | 블록 설치 |
| `1`–`9` · 휠 | 블록 선택 |
| `F5` | 3인칭 ↔ 1인칭 전환 |
| `M` | 음소거 |
| `Esc` | 메뉴 |

## 팁

- `?seed=숫자` 를 URL에 붙이면 다른 세계가 생성됩니다. 예: `?seed=20260707`
- 분홍 산호 블록은 라군 근처 모래밭에서 발견됩니다.

## 기술 스택

- **Three.js r160** (importmap CDN) — 단일 `index.html`, 빌드 불필요, 외부 에셋 0개
- 모든 블록 텍스처는 캔버스에서 절차 생성 (16×16 아틀라스 → `CanvasTexture`)
- 청크(16×16×64) 단위 메싱 — 보이는 면만 생성, 이웃 면 컬링, 꼭짓점 단위 베이크드 AO
- AABB 충돌 물리, DDA 복셀 레이캐스트, WebAudio 효과음, Pointer Lock API
